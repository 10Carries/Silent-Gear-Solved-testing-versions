How the numbers — and the alloy rules — are calculated

Per‑material values. Each cell in your file is read as one or more tokens: a plain number averages in as a base value; +N adds flat; N% with a sign scales the running total; a bare N% averages in as a fraction; xN multiplies the total; a trailing Nx averages in as a multiplier baseline; and name (N) (used for Rarity / Harvest Tier) reads the number in parentheses.

Which materials can alloy together. A material can be a Coating, Grip, Main, etc. depending on which rows it has in your file. Two or more materials can only be alloyed if they share at least one of those roles (in‑game logic, recreated from AlloyMakerBlockEntity), and a shared role is dropped if every material in the recipe is flagged "Additive" for it. Whatever roles survive are the only ones the resulting alloy keeps — so combining Iron and Gold keeps whatever they both do, but drops "Coating" since Iron can't be one.

Combining an alloy. An alloy needs at least 2 different materials — a stack of six of the same material isn't an alloy, so those combinations are excluded entirely. For every surviving shared role, every material's token for that role is pooled, in the order the materials were chosen. Whichever material comes first sets the "primary" baseline that weights every other averaged token — so a different pick for the first slot changes the result, same as in‑game. Materials after the first are treated as an unordered group, matching how the weighting math behaves for anything past the primary slot. Harvest Tier is the one exception — it isn't averaged at all, it simply takes the highest tier among the materials used.

Different roles, different stats. The same materials produce different numbers depending on which role they're filling — Gold+Netherite as a Coating behaves nothing like Gold+Netherite as a Main. Each result lists every surviving role separately with its own stat values, rather than blending them into one number. Ranking is based on whichever role is used as "primary" for that purpose: Main if the alloy keeps it (since it carries most combat/armor stats), otherwise the first surviving role alphabetically — marked in the results.

Synergy. Recreated from the mod's own formula: a bonus for using more distinct materials, a penalty if the parts share no common category, a small bonus for categories shared by more than one part, and a small penalty scaled by how far each part's Rarity sits from the first part's Rarity. Synergy is clamped between 0.1x and 2.0x, and isn't applied to Harvest Tier. Traits are shown/filterable for reference but their exact mechanical effects aren't factored into the math, since that logic isn't data‑driven in the export.

Which station makes it. Four stations exist, each accepting different material categories: the Alloy Forge / Metal Alloyer (Metal and/or Dust), the Super Mixer (any category, added in version 4.0.2), the Recrystalizer (Gem and/or Dust), and the Refabricator (Slime, Fiber, and/or Cloth). Every material in a recipe must match a station's accepted categories for that station to work. All four are slot‑limited (4 slots before version 4.1.5, 6 from 4.1.5 on — except the Super Mixer, which goes from 4 to 8), and you can turn any station off if you don't have access to it. Set your version above and untick any machines you can't use.

Ranking. For every stat you selected, every material/alloy gets a rank — highest final value = rank 1. Ranks across all your selected stats are averaged, and the final list is sorted with the lowest average rank (i.e. the best overall) first.

Search strategy. Order‑sensitive combinations with repeats allowed grow explosively, so there are three ways to handle it. Auto‑narrow scores every eligible material by how strong it is, on its own, across your selected stats, then keeps as many top scorers as fit inside a combination budget (at least 15 materials are always kept, and whitelisted materials are always kept regardless of score). Dynamic filter is more thorough: it runs a full, unnarrowed search at alloy size 3, drops the bottom 10% of materials based on how well they actually performed in that search, then repeats at size 4, 5, and so on up to your chosen max size — each round's pruning is based on real combination results rather than a single material's standalone stats. No narrowing checks every single eligible combination with no pool reduction at all; since that can be billions of combinations, it keeps only the best 1,000 found so far in memory at any point (approximated with a running best‑so‑far comparison), discarding a worse one whenever a better one turns up, so the search can run to completion without crashing the tab. All three are heuristics except "no narrowing," which is a true exhaustive search of your current filters — none of them guarantee the single best possible alloy when narrowed, but auto‑narrow and dynamic filter get you dramatically closer than manual testing, in far less time.
